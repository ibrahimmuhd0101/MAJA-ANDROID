# 🌐 MAJA Social Media

A modern social media app built with Firebase.

## ✨ Features

- ✅ Login / Signup with Firebase Auth
- ✅ Create posts with images
- ✅ Like, Comment, Repost
- ✅ Profile with avatar and gender
- ✅ Search users
- ✅ Add/Remove friends
- ✅ Dark mode
- ✅ Delete account
